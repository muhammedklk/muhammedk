# Muhammed K Portfolio

## Goal
Build an original, production-ready personal portfolio with an editorial 12/8/4-column grid, oversized typography, asymmetric project storytelling, electric-blue and acid-lime accents, and restrained high-quality motion.

## Pages and navigation
- Create shared fixed header, full-screen menu, custom cursor, page transitions, and typographic footer.
- Build distinct routes for Home, About, Work, Contact, and five project case studies.
- Keep all navigation keyboard-accessible, close the menu with Escape, and provide clear current-page and focus states.

## Home experience
- Asymmetric full-viewport hero with staged entrance motion and availability indicator.
- Editorial About, Selected Work, Process, Toolkit marquee, Experience, Stats, Services, and Contact preview sections.
- Five differently composed project features with large, replaceable original presentation imagery.

## Case studies
- Build a reusable art-directed case-study layout for Advanced Leap Co, Green Track, Ronaraiksa, Styleora, and ERP Redesign.
- Include every requested research, flow, design, development, responsive, outcome, learning, stack, and next-project section.
- Use large mockup imagery and project-specific layouts rather than documentation cards.

## Contact
- Build a dedicated editorial contact page with accessible labels and client-side validation.
- Provide a polished success state after valid submission; no external delivery service will be connected.

## Visual system and motion
- Define the complete color, typography, grid, spacing, focus, animation, and responsive token system first.
- Use lightweight CSS/React motion for reveals, marquee, magnetic controls, smooth navigation, and cursor interpolation.
- Disable cursor and hover-dependent effects on touch devices; respect reduced motion.

## Responsive and quality checks
- Create intentional 12-column desktop, 8-column tablet, and 4-column mobile compositions with zero horizontal overflow.
- Verify menu, Escape handling, project links, contact validation, keyboard use, reduced motion, image loading, metadata, and layouts at representative mobile/tablet/desktop widths.
- Add unique metadata for every route, robots support, and clean canonical URLs. A sitemap cannot be finalized until the project has a public domain.

## Technical details
- Use the existing React 19, TanStack Start, Vite 7, and Tailwind CSS v4 foundation.
- Keep visual tokens centralized in the global design system and use reusable components/data for repeated structures.
- Generate original abstract interface/mockup imagery without fake project logos.
- Avoid adding large animation dependencies unless the existing package set already provides them.
