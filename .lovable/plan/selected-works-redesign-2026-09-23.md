# Selected Works Redesign

## Goal
Redesign the Home page Selected Works section and the dedicated Work page into a more premium, art-directed portfolio presentation while preserving the existing visual identity and project content.

## Home page
- Refine the Selected Work heading into a tighter editorial composition with balanced typography and supporting copy.
- Redesign the three featured projects with clearer numbering, stronger metadata, more intentional image crops, and alternating image/content layouts.
- Improve the “See All Projects” ending so it feels connected to the section rather than a detached button.

## Work page
- Rework the opening title and project index for faster scanning and a stronger first impression.
- Present all five projects with consistent information but varied editorial pacing, avoiding repetitive boxed cards.
- Keep every card linked to its dedicated case study and preserve project category, description, tools, and imagery.

## Motion and responsiveness
- Add restrained reveal, image, title, and accent motion with reduced-motion support.
- Ensure clean stacking and readable sizing on desktop, tablet, and mobile with no overlap or horizontal overflow.

## Validation
- Verify Home and Work links, every case-study link, hover/focus states, image loading, responsive layouts, and the latest build status.
